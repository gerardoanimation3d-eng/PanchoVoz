# PanchoVoz

**Español** · [English](#english)

Paquete de voz del mod de Minecraft **Pancho y Pancha** (de Gerardeex). Es lo que hace que el búho hable con su
propia voz (Kokoro), en tu PC, sin internet y sin límite diario.

**No hace falta descargarlo a mano:** el mod lo descarga solo cuando tocas *Pausa → Búho → Instalar voz* y aceptas.
Revisa que llegue completo (SHA-256) y lo instala en `AppData\Roaming\BuhoIA\voz`. El mod lo abre al entrar a un mundo
y se cierra solo al cerrar Minecraft. Solo escucha dentro de tu PC (127.0.0.1): no envía nada a internet.

- Sistema: Windows 10/11 de 64 bits (Mac y Linux, más adelante).
- Tamaño: ~377 MB para descargar, ~488 MB instalado.
- Licencia: GNU GPL v3 o posterior (usa phonemizer y eSpeak NG, que son GPL). El código fuente va dentro del paquete,
  en la carpeta `fuente`, y aquí en [`servidor_voz.py`](servidor_voz.py). Lo que lleva adentro y sus licencias:
  [`LICENCIAS.txt`](LICENCIAS.txt).
- El mod "Pancho y Pancha" **no** es parte de este repositorio y tiene su propia licencia.

## English

Voice package for the Minecraft mod **Pancho and Pancha** (by Gerardeex). It makes the owl speak with its own voice
(Kokoro), on your PC, offline and with no daily limit.

**You don't need to download it by hand:** the mod downloads it when you click *Pause → Owl → Install voice* and
accept. It checks the file (SHA-256) and installs it in `AppData\Roaming\BuhoIA\voz`. The mod starts it when you join a
world and it closes by itself when you close Minecraft. It only listens inside your PC (127.0.0.1): nothing is sent to
the internet.

- System: Windows 10/11 64-bit (Mac and Linux later).
- Size: ~377 MB download, ~488 MB installed.
- License: GNU GPL v3 or later (it uses phonemizer and eSpeak NG, which are GPL). The source code is inside the package
  (`fuente` folder) and here in [`servidor_voz.py`](servidor_voz.py). What it includes and the licenses:
  [`LICENCIAS.txt`](LICENCIAS.txt).
- The "Pancho and Pancha" mod is **not** part of this repository and has its own license.
